밥심

찍어 두기만 하면,
필요한 순간에 한 줄.

같은 엔진과 같은 원칙 위에서 기록 방식만 다른 네 가지 시제품이에요. 모두 서버 없이 이 기기 안에서 동작해요. 사진은 기기에 저장되고, 온보딩은 처음 한 번뿐이에요.

공통 원칙

  • 온보딩 뒤로는 묻지 않아요. 대화형이 아니에요.
  • 사진은 바로 분석하지 않고 저장만 해요. 라벨 칩은 원할 때만 눌러요.
  • 한 줄은 내 기록에서 이어진 것만, 하루 한 번까지, 다음 날이면 사라져요.
  • 자세히·제품 비교·상담은 탭한 뒤에만 보여요. 숫자·잔소리·광고는 없어요.

샘플 기록으로 보는 한 줄 (아래 데모 막대에서 날짜 이동)

4일 전쥐가 났다는 메모와 잦은 커피 → 이미 드신 두부조림·바나나
3일 전쌍화탕 사진과 혈압약 → 감초
2일 전타이레놀과 맥주가 같은 날 → 아세트아미노펜
어제조용한 날
오늘어젯밤 소주 → 물 한 줄, 숙취해소제 비교는 탭 뒤
A

카메라 우선 앱

열면 바로 카메라. 셔터 한 번이면 저장되고, 화면 위에 한 줄이 조용히 떠 있어요.

기록하는 수고
열고 한 번 누르면 끝
놓치는 순간
앱을 열어야만 남아요. 커피·약 같은 사소한 건 빠지기 쉬워요
방해되는 정도
알림 없이, 열었을 때만 봐요
정착 위험
기본 카메라 대신 이 앱을 여는 습관이 필요해요
B

홈 화면 위젯

위젯에 찍기 버튼과 한 줄 자리. 앱은 거의 열지 않아요.

기록하는 수고
홈 화면에서 바로, 가장 짧은 경로
놓치는 순간
밖에선 결국 기본 카메라를 써서 빠지기 쉬워요
방해되는 정도
폰을 볼 때 자연스럽게 눈에 들어와요
정착 위험
위젯을 직접 추가해야 해요
C

앨범에서 가져오기

평소처럼 기본 카메라로 찍고, 가끔 앨범에서 한 번에 가져와요. 한 줄은 알림으로.

기록하는 수고
찍는 건 그대로, 가끔 한 번에 가져오기
놓치는 순간
원래 찍던 사진이 다 들어와 가장 적어요
방해되는 정도
알림이라 타이밍이 중요해요. 하루 한 번까지
정착 위험
앱에서는 자동 스캔이 되지만, 웹 시제품에선 직접 골라야 해요
D

공유하기로 저장

사진 앱에서 공유 → 밥심. 한 줄은 알림 배너로.

기록하는 수고
사진마다 공유 → 앱 선택, 두세 번
놓치는 순간
매번 공유해야 해서 가장 많이 빠져요
방해되는 정도
알림 기반, C와 비슷
정착 위험
권한 부담은 없지만 금방 귀찮아져요
