# 밥심 — 푸드 베이스드 헬스케어 프로토타입

사용자가 일상 언어로 컨디션을 말하면 **먹는 것만**(일상 음식 · 건강기능식품 · 한방 일반의약품) 추천하는 채팅 프로토타입입니다. 백엔드 없는 정적 사이트이며 규칙 기반 엔진(`engine.js`)으로 동작합니다(LLM 미사용).

## 구성 (모바일 우선 탭 앱)
- 첫 실행 시 안전 정보 온보딩(임신·수유, 지병, 복용 약, 알레르기) → localStorage에 저장, '내 정보' 탭에서 수정
- 홈 진입 카드: 🌡️ 오늘 컨디션 체크 · 🍱 식단 기록·칼로리 · 🎁 건강식품 선물 · 🔍 제품 확인(쌍화탕·홍삼 등 → 내 정보 기준 괜찮음/주의/피하기)
- 결과는 카드로: 음식 / 건강기능식품(식약처 인정 기능성 문구) / 한방 일반의약품(허가 효능·효과) / 제외·주의
- 💬 직접 물어보기(보조 채팅): 운동·생활습관은 범위 밖 안내, 위험 신호는 추천 중단
- 데모 모드: 내 정보 탭에서 예시 페르소나(고혈압, 임신+유제품, 아스피린+견과류, 당뇨, 신장질환) 불러오기
- 하단 탭: 홈 · 컨디션 · 식단 · 제품 · 내 정보

## 파일
- `index.html` — UI + 시나리오 플레이어
- `engine.js` — 지식베이스(TOPICS), 안전 규칙(SAFETY_RULES), 대화 엔진

## 로컬 실행
`python3 -m http.server 8000` 후 http://localhost:8000

## 배포
`main` 브랜치에 push하면 GitHub Actions(`.github/workflows/pages.yml`)가 GitHub Pages로 자동 배포합니다.

> ⚠️ 건강기능식품/일반의약품 문구는 요약본입니다. 실제 서비스 전 식약처 고시 및 제품 허가사항 원문 대조가 필요합니다. 이 프로토타입은 진단·처방을 제공하지 않습니다.
