# 밥심 — 한 줄로 물어보는 먹거리 도우미

먹는 것(음식·차 · 건강기능식품 · 한방 일반의약품)으로만 돕는 웹앱 프로토타입입니다. 백엔드 없는 정적 사이트(PWA)이며 규칙 기반 엔진(`engine.js`)으로 동작합니다.

## 원칙: 필요할 때만 돕고, 놓칠 만한 것만 살짝 챙긴다
- 홈은 **한 줄 입력**뿐 (📷 검진표·약 봉투 사진은 샘플을 불러오는 데모). 예시 문구는 입력 힌트로만 표시
- 식사 사진은 작은 보조 기능: 분석·판정 없이 조용히 저장만 하고, 관련 질문을 했을 때나 패턴이 뚜렷할 때만 드물게 한 줄로 반영
- 숫자(칼로리·g·%) 없이 '괜찮아요 / 조금 아쉬워요 / 피하는 게 좋아요'와 한 줄 이유로만 판단
- 되묻지 않고 **답변 카드 하나**: 식습관 인사이트(해당 시) → 지금 하나만 고른다면 → 제외 개수 → 상담 버튼
- 다른 선택지·제품 비교(균주·보장균수·함량·원산지, 인증 배지, 최저가·판매처)·제외 이유는 **자세히 보기** 뒤에. 제품·번호·가격은 모두 **예시 데이터**
- **전문가에게 상담하기**(약사·영양사, 카드 안에서 바로 요청하는 목업): 항상 작게, 증상 지속·약 상호작용·검진 결과일 때 강조
- 위험 신호는 추천을 멈추고 의료진·119 안내, 운동·생활습관은 범위 밖
- **후속 메모는 사용자가 남긴 내용이 이유가 될 때만**: 감기/목 → 다음 날 "목은 좀 괜찮아지셨어요?", 변비 → 며칠 뒤 확인, 고른 제품 → 떨어질 즈음 알림, 검진 LDL을 말한 뒤 야식·튀김을 적으면 카드 안에서 가볍게 상기. 없으면 홈은 입력창만
- ⚙️ 설정: 안전 정보(임신·수유, 지병, 복용 약, 알레르기, 선택: 검진 결과) · 데모 페르소나

## 파일
- `index.html` — UI(한 줄 입력, 답변 카드, 후속 메모, 상담 목업, 설정)
- `engine.js` — 지식베이스, 안전 규칙, 답변(answer)·제품 비교 예시 데이터
- `manifest.webmanifest`, `sw.js`, `icons/` — PWA

## 배포
`main`에 push하면 GitHub Actions가 GitHub Pages로 배포합니다.

> ⚠️ 건강기능식품/일반의약품 문구는 요약본입니다. 실제 서비스 전 식약처 고시 및 제품 허가사항 원문 대조가 필요합니다. 진단·처방을 제공하지 않습니다.
