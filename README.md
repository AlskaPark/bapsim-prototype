# 밥심 — 오늘의 한 끼

먹는 것(음식 · 건강기능식품 · 한방 일반의약품)으로만 컨디션을 가볍게 챙기는 위젯형 웹앱 프로토타입입니다. 백엔드 없는 정적 사이트(PWA)이며 규칙 기반 엔진(`engine.js`)으로 동작합니다.

## 질문 없는, 먼저 보여주는 카드
- 앱을 열거나 위젯을 보면 **오늘의 카드가 바로** 떠요: 오늘의 한 가지 + 대안 1~2개 + 내 정보 기준 제외 항목
- 앱이 이미 아는 맥락으로 고름: 안전 정보(임신·수유, 지병, 복용 약, 알레르기, 선택: 검진 결과) · 계절/환절기 · 시간대(다음 끼니) · 요일(월요일 아침, 주말 아침 등) · 최근 피드백
- 유일한 상호작용은 카드 위의 가벼운 피드백: **↻ 오늘은 좀 달라요**(다음 후보로 교체) 또는 **한 줄로 알려주기**(예: "속이 더부룩해요") — 알려준 내용은 다음 날 카드에 조용히 반영
- 검진 결과는 순서를 조용히 조정 + "의사의 안내를 우선" 문구
- 위험 신호(고열·흉통 등)를 적으면 추천을 멈추고 의료진 상담 안내
- ⚙️ 설정: 안전 정보 · 데모 페르소나 · 시간·상황 시뮬레이터(월요일 아침, 금요일 밤 다음날, 한여름, 겨울 밤 등)
- 홈 화면 위젯 미리보기(iOS/Android 소형·중형)도 같은 카드

## 파일
- `index.html` — UI(홈 위젯, 위젯 미리보기, 설정)
- `engine.js` — 지식베이스, 안전 규칙, 흐름(FLOW)·결과(getResult)
- `manifest.webmanifest`, `sw.js`, `icons/` — PWA

## 배포
`main`에 push하면 GitHub Actions가 GitHub Pages로 배포합니다.

> ⚠️ 건강기능식품/일반의약품 문구는 요약본입니다. 실제 서비스 전 식약처 고시 및 제품 허가사항 원문 대조가 필요합니다. 진단·처방을 제공하지 않습니다.
